# Emergency Mini Floodlight

<img src = "images/minifloodlight.jpg" width="70%" alt="mini flood light"/>

*The light you can depend when everything goes dark.*

### About the Product
Designed to be reliable in every emergency situation. Compact, lightweight, and durable. With up to 12 hours continuous light.

### Features
- Durable build
- Compact and lightweight
- Splash resistant
- Rechargeable (Compatible with most cellphone chargers)
- Cross-compatible with 6v solar panels
- Wireless remote control

### Want to build one yourself?
Feel free to check on the list of materials used.
- Outdoor waterproof electrical box with clear cover (100 * 68 * 50mm)
- 18650 Lithium ion battery (3 pcs)
- 1S BMS 12A capacity
- USB type-c charging port
- 25W LED source board with charging indicator (with remote included)
- 2 AAA battery (for the remote)
- wires, silicone sealant and soldering tools (for assembly)
